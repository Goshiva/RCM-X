📊 API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

DOCUMENT PROCESSING:
  POST /api/upload-pdf               - Process medical PDF
  POST /api/predict-hcc              - Predict HCC codes

CODE VALIDATION:
  GET  /api/validate-icd10/<code>   - Validate ICD-10 code
  GET  /api/find-icd10/<condition>  - Find codes by condition

RISK CALCULATION:
  POST /api/calculate-risk           - Calculate RAF & premiums
  POST /api/generate-report          - Generate report (pdf/json/csv/txt)
  GET  /api/download-report/<file>  - Download report

COMPLIANCE:
  GET  /api/audit-trail/<patient>    - Patient audit trail
  GET  /api/compliance-summary       - Compliance report
  GET  /api/hcc-reference            - HCC database reference

MONITORING:
  GET  /api/health                   - Health check
